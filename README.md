# Ninth & Oak

Premium consulting website for Ninth & Oak, built with Astro and prepared for Netlify continuous deployment.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

Netlify reads the build and publish settings from `netlify.toml`. The consultation form uses Netlify Forms and appears in the Netlify dashboard after the first production deployment. Email notifications can then be configured under **Forms → Form notifications**.

The intended custom domain is `ninthandoak.com`. DNS should not be changed until domain ownership is confirmed.
